### 🔍 發現的問題（更新: 2025-10-12 09:30）

#### 🔴 **CRITICAL**: 求解器根本性錯誤
- **Newton-Raphson 殘差計算完全錯誤**: 使用 `F = J*x - b` 而非正確的 KCL 殘差
- **線性電路意外通過**: 錯誤的公式在線性情況下碰巧給出正確結果
- **非線性電路必然失敗**: 無法處理二極體、MOSFET 的指數項
- **參考**: 詳見 [`docs/SOLVER_FUNDAMENTAL_ERROR.md`](docs/SOLVER_FUNDAMENTAL_ERROR.md) ⚠️ **必讀**

#### 測試質量問題（3大類、30-40個受影響）

1. **🔴 跳過失敗 (6處 - 最嚴重)**:
   - 檢測到 `result.success === false` 時直接 `return`
   - 測試被標記為「通過」，但實際功能失敗
   - 掩蓋了引擎在複雜非線性電路中的嚴重收斂問題
   
2. **🟡 過於寬鬆的容錯率 (15+處)**:
   - KCL/KVL 允許 10% 誤差（應該 < 0.1%）
   - 功率平衡允許 15% 誤差（應該 < 1%）
   - 阻尼振幅允許**增加** 10%（應該嚴格遞減！）
   - 諧振頻率、時間常數允許 10-11% 誤差（應該 < 1%）
   
3. **🟠 驗證不足 (8+處)**:
   - DC 電路只檢查 `success`，不檢查電壓值
   - 元件測試只打印警告，不拋出錯誤

4. **🟡 無效的斷言模式 (80+處)**:
   - 50+ 使用 `toBeDefined()` - 無法檢測數值錯誤
   - 30+ 使用 `toBeGreaterThan(0)` - 容差過於寬鬆
   - 1 個使用 `toBeCloseTo(..., 0)` - 允許 50% 誤差

### ⚠️ 已知的測試失敗 (4 個)

所有失敗均出現在 `tests/integration/circuits/nonlinear.test.ts` 中的複雜瞬態分析：

1. **簡單二極體整流電路** - 瞬態分析
   - 失敗原因: `result.success = false` (收斂失敗)
   - 電路: 10V 正弦波 → 二極體 → 1kΩ 負載
   - 問題: Newton-Raphson 在處理二極體快速開關時難以收斂

2. **多個非線性元件的穩定性**
   - 失敗原因: `result.success = false` (收斂失敗)
   - 電路: 10V DC → 1kΩ → 二極體 → 100Ω → MOSFET → GND
   - 問題: 兩個非線性設備的交互作用增加了求解複雜度

3. **快速脈衝信號下的穩定性**
   - 失敗原因: `result.success = false` (收斂失敗)
   - 電路: 1MHz 脈衝 (10ns 上升時間) → 二極體 → RC 電路
   - 問題: 極快的信號變化率導致時間步長極小，Newton 迭代困難

4. **MOSFET 快速開關**
   - 失敗原因: `result.success = false` (收斂失敗)
   - 電路: 1MHz 方波閘極驅動 → MOSFET → 100Ω 負載
   - 問題: MOSFET 工作區域快速轉換導致雅可比矩陣劇烈變化

**根本原因分析**:
- 🔴 **收斂策略不足**: 當前 Newton-Raphson 求解器缺乏足夠的阻尼和自適應控制
- 🔴 **時間步長控制**: 快速瞬態需要更智能的時間步長自適應算法
- 🔴 **初始猜測**: 非線性工作區域轉換時缺少良好的初始值預測
- 🔴 **雅可比矩陣**: 可能存在數值條件問題

**改進建議**:
1. 實施帶阻尼的 Newton-Raphson (damped Newton method)
2. 增強自適應時間步長控制（基於收斂速度調整）
3. 實施預測-校正方法改善初始猜測
4. 添加更多的收斂診斷和恢復策略
