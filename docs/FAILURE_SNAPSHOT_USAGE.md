# 🔬 失敗快照系統使用指南

## 概述

失敗快照系統 (Failure Snapshot Diagnostics) 在收斂失敗時自動捕獲完整的系統狀態，生成易於分析的文本文件，幫助您區分「程式 BUG」和「真正的數值收斂問題」。

**生成日期**: 2024-10-13  
**狀態**: ✅ 已完成並測試

---

## 🎯 設計目標

根據用戶的"法醫調查"理念：

> 將所有問題都歸咎於'收斂失敗'是一種思維惰性

失敗快照系統提供完整的"犯罪現場證據"，讓您能夠：

1. **區分謀殺與心臟病發作**: 是代碼 BUG 還是真正的數值病態？
2. **外部驗證**: 使用 Python/MATLAB 獨立重現問題
3. **深度診斷**: 檢查 Jacobian 條件數、奇異值、rank
4. **Newton 重放**: 驗證是否為線性求解器問題

## 📊 文件詳解

### 1. `*_meta.json` - 元數據

包含完整的失敗上下文：

```json
{
  "time": 1.131e-6,
  "timeStep": 1e-12,
  "attemptedTime": 1.132e-6,
  "systemSize": 8,
  "matrixNonzeros": 42,
  "tolerance": 1e-6,
  "maxIterations": 50,
  "failureReason": "All MCAS layers failed",
  "failureLayer": "MCAS-L3",
  "timestamp": "2025-10-13T13:22:11.753Z"
}
```

**關鍵字段**:
- `time`: 失敗時刻 (秒)
- `timeStep`: 當前時間步長
- `failureLayer`: 失敗的 MCAS 層（L1/L2/L3）
- `systemSize`: 系統方程數量

### 2. `*_solution.txt` - 解向量（文本CSV）

**格式**: `Index,Value`

```csv
Index,Value
0,1.2000001926747734e+1
1,0.0000000000000000e+0
2,1.0000001594188900e+1
3,7.6132374420600870e+0
4,4.0194663110307868e-6
...
```

**說明**:
- 第一列：節點索引
- 第二列：節點電壓 (V)
- **完全精度**: 16位有效數字

**如何分析**:
```bash
# 快速查看所有值
cat failure_*_solution.txt

# 找出異常值（> 1000V 或 NaN）
grep -v "e-" failure_*_solution.txt | grep "e+"

# 統計非零元素
grep -v "0.0000000000000000e+0" failure_*_solution.txt | wc -l
```

### 3. `*_residual.txt` - 殘量向量（文本CSV）

**格式**: 同 solution.txt

```csv
Index,Value
0,2.3921343790311855e-5
1,0.0000000000000000e+0
2,1.9968993135860729e-5
...
```

**物理意義**:
- 殘量 = F(x) - 0（應該接近零）
- 較大殘量表示方程未滿足

**診斷標準**:
- `||r|| < 1e-6`: 良好收斂
- `1e-6 < ||r|| < 1e-3`: 收斂困難
- `||r|| > 1e-3`: 嚴重發散

### 4. `*_jacobian.mtx` - Jacobian 矩陣 (MatrixMarket 格式)

**格式**: 稀疏矩陣標準格式

```
%%MatrixMarket matrix coordinate real general
% Generated by AkingSPICE Failure Snapshot System
8 8 42
1 1 1.0000000000000000e+0
1 3 -1.0000000000000000e+0
2 2 1.0000000000000000e+0
...
```

**說明**:
- 第1行: 頭部（格式聲明）
- 第2-3行: 註釋
- 第4行: `行數 列數 非零元素數`
- 後續行: `行索引 列索引 值` (索引從1開始)

**如何分析**:
```python
import scipy.io as sio
J = sio.mmread('failure_*_jacobian.mtx')

# 檢查對角線
import numpy as np
diag = J.diagonal()
print(f"零對角元素: {np.sum(np.abs(diag) < 1e-15)}")
print(f"最小對角: {np.min(np.abs(diag)):.2e}")
```

### 5. `*_newton_history.csv` - Newton 迭代歷史

**格式**: 

```csv
iteration,residual_norm,solution_norm,delta_norm,timestamp
0,0.00003232,17.377,0.00003127,1760361730753
1,1.164e-10,17.377,3.963e-13,1760361730754
2,1.164e-10,17.377,1.208e-15,1760361730754
...
```

**關鍵列**:
- `iteration`: 迭代次數
- `residual_norm`: ||F(x)||（應該遞減）
- `delta_norm`: ||Δx||（牛頓步長）
- `timestamp`: 時間戳（毫秒）

**收斂模式識別**:

| 模式 | 特徵 | 診斷 |
|------|------|------|
| **正常收斂** | ||r|| 快速降至 < 1e-10 | ✅ 無問題 |
| **卡在局部最小** | ||r|| 降至某值後不變 | ⚠️ 初猜問題或 Jacobian 病態 |
| **震盪** | ||r|| 上下跳動 | ⚠️ 步長太大或病態 |
| **發散** | ||r|| 持續增大 | 🔥 模型錯誤或嚴重病態 |
| **立即爆炸** | 第1次迭代 ||r|| > 1e10 | 🔥 Jacobian 錯誤或奇異 |

**範例分析**:
```python
import pandas as pd
import matplotlib.pyplot as plt

df = pd.read_csv('failure_*_newton_history.csv')

plt.semilogy(df['iteration'], df['residual_norm'], 'o-')
plt.xlabel('Iteration')
plt.ylabel('||Residual||')
plt.title('Newton Convergence')
plt.grid(True)
plt.show()
```

## 📈 診斷流程

### Step 1: 查看摘要報告

```bash
cat snapshots/failure_*_summary.txt
```

**快速判斷**:
- 如果 `||r||` 接近 1e-6 但仍失敗 → 可能是容忍度設置問題
- 如果 `殘量下降比` < 10 → Newton 根本沒收斂
- 如果有 NaN/Inf → 模型錯誤或初始條件問題

### Step 2: 檢查 Newton 迭代歷史

```bash
cat snapshots/failure_*_newton_history.csv
```

**模式識別**:
1. **第0次迭代殘量正常，第1次爆炸** → Jacobian 錯誤
2. **殘量持續下降但太慢** → 病態矩陣
3. **殘量降到某值後卡住** → 局部最小值或數值精度問題

### Step 3: 運行 Python 驗證

```bash
cd snapshots/
python failure_*_verify.py
```

**關鍵檢查**:
1. **條件數** < 1e10: 可接受
   條件數 > 1e12: 需要預條件子
2. **Python Newton 能收斂**: 您的求解器有 BUG
   Python Newton 也不收斂: 真正的數值問題

### Step 4: 外部工具深度分析

#### 使用 MATLAB:
```matlab
J = mmread('failure_*_jacobian.mtx');
r = load('failure_*_residual.txt');

% 條件數
cond_num = condest(J);
fprintf('Condition number: %.2e\n', cond_num);

% SVD
[U, S, V] = svd(full(J));
smallest_sv = S(end, end);
fprintf('Smallest singular value: %.2e\n', smallest_sv);

% Rank
r = rank(full(J));
fprintf('Matrix rank: %d / %d\n', r, size(J, 1));
```

#### 使用 NumPy:
```python
import numpy as np
from scipy.io import mmread

J = mmread('failure_*_jacobian.mtx').todense()

# 條件數
cond = np.linalg.cond(J)
print(f'Condition number: {cond:.2e}')

# 特徵值
eigvals = np.linalg.eigvals(J)
print(f'Smallest |eigenvalue|: {np.min(np.abs(eigvals)):.2e}')

# Rank
rank = np.linalg.matrix_rank(J)
print(f'Rank: {rank} / {J.shape[0]}')
```

## 🎯 常見問題診斷

### Q1: "Newton 達到最大迭代但殘量很小"

**症狀**: `||r|| ≈ 1e-9` 但失敗

**診斷**:
1. 檢查 `tolerance` 設置（可能太嚴格）
2. 查看最後幾次迭代的 `delta_norm`（可能已收斂但判斷條件有問題）

**解決方案**:
- 放寬容忍度: `tolerance: 1e-5`
- 或添加 `delta_norm < 1e-10` 作為收斂標準

### Q2: "殘量第一次迭代就爆炸"

**症狀**: 
```
迭代 0: ||r|| = 3.2e-5
迭代 1: ||r|| = 1.8e+10  ← 爆炸！
```

**診斷**:
1. Jacobian 計算錯誤（導數不匹配）
2. Jacobian 奇異（有零對角元素）
3. 線性求解器失敗（NaN propagation）

**驗證步驟**:
```python
# 檢查 Jacobian 對角線
J = mmread('failure_*_jacobian.mtx')
diag = J.diagonal()
zero_diag = np.sum(np.abs(diag) < 1e-15)
print(f'Zero diagonal: {zero_diag}')  # 應該 = 0

# 檢查線性解
delta = spla.spsolve(J.tocsr(), -r)
print(f'||delta||: {np.linalg.norm(delta):.2e}')  # 應該 < 1
```

### Q3: "Python 能收斂但您的程式不能"

**症狀**: Python `verify.py` 顯示 ✅ 但您的程式失敗

**診斷**: 線性求解器或迭代控制有 BUG

**排查方向**:
1. 檢查線性求解器 pivot 處理
2. 檢查 Newton 更新公式: `x_new = x_old + damping * delta`
3. 檢查收斂判斷邏輯（可能誤判）

### Q4: "條件數 > 1e15，怎麼辦？"

**症狀**: Jacobian 嚴重病態

**根本原因** (常見):
- MOSFET/Diode 在開關瞬間電阻變化 10^10 倍
- 時間步長極小（< 1ps）導致數值病態
- 電容/電感與極小 dt 組合產生巨大係數

**解決方案**:
1. **Matrix Preconditioning** (最有效):
   - 實現 ILU 預條件子
   - 預計 2-3 週開發
2. **增大 Gmin** (臨時):
   - `Gmin = 1e-6` → `1e-4`
3. **限制最小 dt**:
   - `minTimeStep = 1e-12` → `1e-10`
4. **使用更穩健的積分器**:
   - Backward Euler fallback

```python
import glob
import pandas as pd

# 載入所有 Newton 歷史
all_histories = []
for csv_file in glob.glob('snapshots/*_newton_history.csv'):
    df = pd.read_csv(csv_file)
```
