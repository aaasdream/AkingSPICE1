# MOSFET PWM RL 電路驗證：如何確認結果正確

## 簡答

我們通過 **三層驗證策略** 來確認結果正確性：

### ✅ 1. 理論計算對比（最重要）

RL 電路的充電過程有精確的解析解，可以直接對比：

```
電流: i(t) = I_steady × (1 - e^(-t/τ))
電壓: V_L(t) = VDD × e^(-t/τ)
```

其中：
- `I_steady = VDD / R` = 1.2A (穩態電流)
- `τ = L / R` = 10µs (時間常數)

**關鍵檢查點**：

| 時間 | 理論電流 | 預期誤差 |
|------|---------|----------|
| t = 1τ (10µs) | 0.7585 A | < 5% |
| t = 2τ (20µs) | 1.0376 A | < 5% |
| t = 3τ (30µs) | 1.1402 A | < 5% |
| t = 5τ (50µs) | 1.1919 A | < 5% |

### ✅ 2. 物理定律檢查

確保模擬結果符合基本物理：

- **初始條件**: i(0) = 0 (電感電流不能突變)
- **單調性**: 電流應該單調增加
- **上界**: i(t) ≤ I_steady (不超過穩態值)
- **KVL**: VDD = V_R + V_DS + V_L (基爾霍夫電壓定律)

### ✅ 3. 與 ngspice 對比

使用工業標準軟體 ngspice 運行相同電路，對比波形。

## 如何判斷結果正確

### ✅ 結果正確的標誌

1. **理論對比**：
   - 關鍵時間點誤差 < 5%
   - 穩態值誤差 < 5%

2. **物理合理**：
   - 初始電流為 0
   - 電流單調增加
   - 最終收斂到 I_steady

3. **與 ngspice 一致**：
   - 波形形狀相同
   - 關鍵點誤差 < 5%

4. **數值穩定**：
   - 無 NaN 或 Inf
   - 無異常振盪

### ❌ 結果錯誤的跡象

1. **理論偏差大** (>10%)：
   - MOSFET 模型參數錯誤
   - 電路拓撲錯誤
   - 總電阻計算錯誤

2. **物理不合理**：
   - 電流出現負值
   - 電流振盪
   - 超過穩態上界

3. **數值問題**：
   - NaN 或 Inf 出現
   - Newton 不收斂
   - 步長過大導致失真
