# MOSFET PWM RL 電路驗證指南

## 概述

本文檔說明如何驗證 AkingSPICE 2.1 的 MOSFET PWM RL 電路模擬結果的正確性。

## 驗證策略

### 1. 理論計算對比 ⭐⭐⭐ (最重要)

對於 RL 電路的充電過程，我們有精確的解析解：

#### 電流方程
```
i(t) = I_steady × (1 - e^(-t/τ))
```

其中：
- `I_steady = VDD / R_total` (穩態電流)
- `τ = L / R` (時間常數)

#### 電感電壓方程
```
V_L(t) = VDD × e^(-t/τ)
```

#### 關鍵時間點的理論值

對於我們的測試參數 (VDD=12V, R=10Ω, L=100µH):
- `τ = 100µH / 10Ω = 10µs`
- `I_steady = 12V / 10Ω = 1.2A`

| 時間點 | 電流理論值 | 百分比 |
|--------|-----------|--------|
| t = 0  | 0.0000 A  | 0%     |
| t = 1τ (10µs) | 0.7585 A | 63.2% |
| t = 2τ (20µs) | 1.0376 A | 86.5% |
| t = 3τ (30µs) | 1.1402 A | 95.0% |
| t = 5τ (50µs) | 1.1919 A | 99.3% |
| t = ∞  | 1.2000 A | 100%   |

### 2. 物理定律檢查 ⭐⭐

#### 2.1 初始條件
- 電感電流在 t=0 時必須為 0（電感電流不能突變）

#### 2.2 單調性
- 充電過程中電流應該單調增加
- 不應該出現振盪或負值

#### 2.3 電流上界
- 電流不應超過 `I_steady = VDD/R`
- 允許微小的數值超調（<1%）

#### 2.4 基爾霍夫電壓定律 (KVL)
```
VDD = V_RD + V_DS + V_L + V_RS
```

#### 2.5 能量守恆
- 輸入能量 = 電阻消耗 + 電感儲能
- `E_input = ∫ VDD × i(t) dt`
- `E_resistor = ∫ i²(t) × R dt`
- `E_inductor = ½ L × i(t_final)²`

### 3. 與 ngspice 對比 ⭐⭐⭐

使用 ngspice (工業標準) 運行相同電路，對比波形。

## 驗證流程

### 第一階段：理論驗證 (快速)

1. 運行 AkingSPICE 驗證測試
   ```bash
   node test_mosfet_rl_validation.js
   ```

2. 檢查輸出報告
   - 關鍵時間點誤差
   - 穩態誤差
   - 物理定律檢查
   - 數值穩定性

3. 判斷標準
   - **PASS**: 所有檢查通過 → 結果正確
   - **FAIL**: 有檢查失敗 → 需要調試

### 第二階段：ngspice 對比 (詳細)

1. 運行 ngspice 參考測試
   ```bash
   ngspice -b test_mosfet_rl_reference.cir -o reference.log
   ```

2. 對比關鍵測量值
   - 在 1τ, 2τ, 3τ, 5τ 時間點
   - 穩態電流
   - DC 工作點

3. 判斷標準
   - 誤差 < 5%: ✅ 優秀
   - 誤差 5-10%: ⚠️ 可接受
   - 誤差 > 10%: ❌ 需要調試

### 第三階段：波形對比 (可選)

1. 生成對比圖表
   ```bash
   python compare_waveforms.py
   ```

2. 視覺檢查
   - 波形形狀是否一致
   - 是否有異常振盪
   - 穩態是否收斂

## 常見問題診斷

### 問題 1: 理論誤差過大 (>10%)

**可能原因**:
- MOSFET 未完全導通 (Vgs 不足)
- MOSFET 模型參數不正確
- 電阻值計算錯誤
- 電感初始條件不正確

**診斷方法**:
1. 檢查 DC 工作點的 MOSFET Vgs, Vds
2. 確認 MOSFET 在線性區或飽和區
3. 確認總電阻 = RD + RS + Ron (MOSFET導通電阻)

### 問題 2: 電流不單調

**可能原因**:
- 數值振盪 (時間步長太大)
- 電感模型不穩定
- Newton 迭代不收斂

**診斷方法**:
1. 減小最大時間步長
2. 檢查 Newton 迭代日誌
3. 檢查電感伴隨模型係數

### 問題 3: 與 ngspice 差異大

**可能原因**:
- MOSFET 模型參數不匹配
- 積分器設定不同
- 容差設定不同

**診斷方法**:
1. 確認 MOSFET 模型參數完全一致
2. 確認使用相同的數值方法
3. 放寬容差重新測試

### 問題 4: 穩態未達到理論值

**可能原因**:
- 模擬時間不夠長 (需要 5τ 以上)
- MOSFET 導通電阻被忽略
- 電路拓撲錯誤

**診斷方法**:
1. 延長模擬時間到 10τ
2. 計算實際的 R_total (包含 Ron)
3. 檢查電路連接
