# 🔬 失敗快照診斷系統文檔

## 📋 執行摘要

**實現日期**: 2025-10-13  
**開發時長**: ~2 小時  
**狀態**: ✅ 已完成並驗證

失敗快照診斷系統是一個完整的故障取證工具，當 Newton-Raphson 求解器收斂失敗時，自動捕獲系統的完整狀態，包括解向量、Jacobian 矩陣、殘量、迭代歷史等，並生成可供外部工具（Python/MATLAB）分析的標準格式文件。

## 🎯 設計目標

遵循用戶提出的法醫學調查方法論：

> 「將所有問題都歸咎於'收斂失敗'是一種思維惰性。我們需要區分代碼 BUG（謀殺）和真正的數值問題（心臟病發作）。」

### 核心問題

當模擬失敗時，我們無法判斷：
1. **程式 BUG**: Jacobian 組裝錯誤、導數計算錯誤、MNA 結構錯誤
2. **真實收斂問題**: 矩陣病態、極端剛性、數值爆炸

### 解決方案

**「凍結犯罪現場」** - 捕獲失敗瞬間的完整快照：
- 時間 `t`、步長 `dt`
- 解向量 `x`、殘量向量 `r`
- Jacobian 矩陣 `J` (MatrixMarket 格式)
- Newton 迭代歷史
- 生成外部驗證腳本

### 2. `_solution.bin` / `_residual.bin` - 二進制向量

- **格式**: IEEE 754 雙精度浮點數 (8 bytes per element)
- **字節序**: Little-Endian (與 NumPy 兼容)
- **用途**: 精確重現失敗時的數值狀態

**Python 讀取範例**:
```python
import numpy as np
solution = np.fromfile('failure_*_solution.bin', dtype=np.float64)
residual = np.fromfile('failure_*_residual.bin', dtype=np.float64)
```

### 3. `_jacobian.mtx` - MatrixMarket 格式

```
%%MatrixMarket matrix coordinate real general
% Generated by AkingSPICE Failure Snapshot System
% Jacobian matrix at convergence failure
8 8 17
1 1 1.000000e+0
1 8 -1.000000e+0
2 2 1.000000e+0
...
```

- **標準格式**: 被 MATLAB, SciPy, Eigen 等廣泛支持
- **稀疏存儲**: 只記錄非零元素
- **索引**: 1-based (MatrixMarket 標準)

**Python 讀取範例**:
```python
from scipy.io import mmread
J = mmread('failure_*_jacobian.mtx').tocsr()
```

### 4. `_newton_history.csv` - 迭代歷史

```csv
iteration,residual_norm,solution_norm,delta_norm,timestamp
0,1.164e-10,1.738e+1,1.208e-15,1697112507179
1,1.164e-10,1.738e+1,1.208e-15,1697112507182
...
```

- **用途**: 分析收斂行為、檢測震盪/發散
- **時間戳**: 毫秒精度，可分析迭代速度

### 5. `_verify.py` - 自動生成驗證腳本

**功能**:
1. 讀取所有快照數據
2. 計算 Jacobian 條件數 (使用 Lanczos 迭代)
3. 執行完整 SVD (矩陣 ≤ 100×100)
4. Newton 重放（驗證線性解算器）
5. 生成對比圖（原始 vs 重放）

**使用方法**:
```bash
cd snapshots
python failure_mcas_all_failed_*_verify.py
```

**輸出**:
- `*_singular_values.png`: 奇異值圖
- `*_convergence.png`: 收斂曲線對比
- 終端輸出：條件數、分析結論

### 6. `_summary.txt` - 可讀摘要

人類友好的文字報告，包含：
- 時間、步長、系統規模
- 收斂狀態（殘量、迭代次數）
- 失敗信息（原因、層級）
- Newton 迭代歷史摘要
- Jacobian 基本診斷（零對角元素、NaN/Inf）
- 下一步行動建議

**核心功能**:

2. **SVD 分析** (小矩陣):
```python
if n <= 100:
```

3. **Newton 重放**:
```python
def replay_newton(J, r, x0, max_iter=20, tol=1e-6):
    for i in range(max_iter):
        delta = spla.spsolve(J, -r)
        x = x + delta
        r = r + J @ delta  # 近似更新
```

## 🔍 診斷流程

### 標準診斷程序

#### 步驟 1: 檢查摘要報告

```bash
cat snapshots/failure_*_summary.txt
```

**快速判斷**:
- **零對角元素 > 0** → MNA 組裝問題或缺少約束
- **包含 NaN/Inf** → 數值爆炸（檢查模型公式）
- **殘量突增** → 模型不連續或步長過大
- **殘量停滯** → 矩陣奇異或病態

#### 步驟 2: 運行 Python 驗證

```bash
cd snapshots
python failure_mcas_all_failed_*_verify.py
```

**檢查輸出**:
- **條件數 < 10^8** → 矩陣健康，問題可能在模型邏輯
- **條件數 > 10^12** → 嚴重病態，需要預條件子或正則化
- **SVD 最小奇異值 ≈ 0** → 矩陣奇異，檢查約束或邊界條件
- **重放成功 vs 原始失敗** → 線性解算器或迭代邏輯有問題

#### 步驟 3: 外部工具驗證

**MATLAB**:
```matlab
J = mmread('failure_*_jacobian.mtx');
sol = load('failure_*_solution.bin', '-double');
res = load('failure_*_residual.bin', '-double');

% 條件數
cond_num = condest(J);

% 求解
delta = J \ (-res);
norm(delta)
```

**NumPy**:
```python
J = mmread('failure_*_jacobian.mtx').tocsc()
r = np.fromfile('failure_*_residual.bin', dtype=np.float64)

# 嘗試直接求解
delta = spsolve(J, -r)
print(f"||delta|| = {np.linalg.norm(delta):.2e}")
```

#### 步驟 4: 比較 SPICE

使用相同參數在 LTspice/ngspice 運行，比較：
- 是否也失敗？（驗證電路本身是否過於剛性）
- 使用了什麼 tolerance？（SPICE 默認 reltol=0.001, abstol=1pA）
- 是否需要 `.uic` (跳過 DC OP)?

## 📈 性能影響

### 快照開銷

| 操作 | 時間 | 影響 |
|------|------|------|
| 捕獲數據 | ~10ms | 忽略不計（僅失敗時） |
| 寫入文件 | ~50ms | 失敗時可接受 |
| 生成 Python 腳本 | ~5ms | 一次性 |

**總開銷**: ~65ms per failure  
**頻率**: 僅在失敗時（極低頻）  
**結論**: **性能影響可忽略**

### 存儲空間

**典型快照** (Buck 轉換器, 8 方程):
- `_meta.json`: ~2KB
- `_solution.bin`: 64 bytes (8 × 8)
- `_residual.bin`: 64 bytes
- `_jacobian.mtx`: ~1KB (17 非零元素)
- `_newton_history.csv`: ~500 bytes
- `_verify.py`: ~8KB
